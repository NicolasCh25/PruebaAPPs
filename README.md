# Cartelera de Películas

Una aplicación web que muestra información actualizada de películas obtenidas desde la API pública de The Movie Database (TMDb). Este proyecto fue desarrollado con fines académicos para comprender la integración de APIs RESTful, despliegue en la nube y evaluación de rendimiento web.

## Estructura del Proyecto
- Frontend: Interfaz web desarrollada con HTML, CSS y JavaScript.
- Backend: Construido con Node.js y Express.js, encargado del consumo de APIs y gestión de endpoints.
- Frontend hospedado en Netlify
- Backend desplegado en Render
- Pruebas de rendimiento: Realizadas con PageSpeed de Google.

## Funcionalidades Principales
- Visualización de películas con información detallada.
- Integración con API pública de TMDb.
- Consumo de una API privada para la gestión de favoritos.
- Evaluación del rendimiento mediante PageSpeed Insights.

## Metodología de Trabajo

El equipo aplicó la metodología SCRUM, realizando planificación por sprints:
### Sprint 0:
- Configuración del entorno de desarrollo.
- Definición de roles y requisitos.
- Estructuración inicial del proyecto.
### Sprint 1:
- Implementación del consumo de APIs públicas y privadas.
- Integración de componentes frontend con el backend.
- Pruebas de rendimiento y despliegue.
